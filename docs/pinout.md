# Pinout Configuration

## STM32F103VET6 Pin Mapping

| **Function** | **Pin** | **Type** | **Description** |
|--------------|---------|----------|-----------------|
| **LED2**     | PE6     | Output   | Active Low (0=ON, 1=OFF) |
| **USART1 TX**| PA9     | AF Push-Pull | Serial Transmit |
| **USART1 RX**| PA10    | Input    | Serial Receive |
| **VDD**      | -       | Power    | 3.3V Supply |
| **VSS**      | -       | Ground   | Common Ground |
